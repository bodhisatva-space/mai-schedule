# Пары и автоматы

Статический сайт для GitHub Pages: HTML, CSS, JavaScript, без сборки и зависимостей.

- Исходники и публикация: `docs/`.
- Расписание и условия: `docs/data.js`.
- Точка отсчёта верхней недели: `calendar.upperMonday` в `docs/app.js`, понедельник в формате `YYYY-MM-DD`. Подтверждённая верхняя неделя начинается 28 сентября 2026 года.
- Сегодня определяется по московскому времени. Навигация листает календарь по неделям.
- Каникулы, переносы и границы семестра не заданы в источнике и не вычисляются.

## Локально

```sh
python3 -m http.server 8000 --directory docs
```

Открыть http://localhost:8000.

## GitHub Pages

В публичном репозитории: Settings → Pages → Deploy from a branch → main → /docs → Save.
Изменения в `docs/` публикуются после push. Пользователям не нужен аккаунт.
